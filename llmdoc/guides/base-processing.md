# 底面处理 Demo

左侧「底面处理」使用当前工作台模型的独立几何副本。顶部语言、导入、示例、项目与导出沿用工作台公共栏；面板中不再单独选择模型。处理不会写回原模型、分色方案、拆分结果或打印确认，也不加入现有项目持久化结构。

## 使用

1. 从顶部导入模型或打开示例，进入「底面处理」。左侧面板提供底面预览、X / Y / Z 切割方向、切入深度和翻转保留侧；默认 Y 为水平切底。「翻转保留侧」只交换保留区域，不改变切面位置。
2. 在左侧「切割方向」中选择 X / Y / Z，分别对应切面法线沿该坐标轴（Y 为水平切面）。仅支持这三种标准角度；不再提供切平面旋转 gizmo、自由旋转、角度输入或角度吸附。视口拖动仅用于观察模型。
3. 按毫米拖动切入深度或输入数值。预览默认显示紫色切割平面和半透明红色删除区域。
4. 左侧顶部小窗实时朝向切面外侧，黄色实心区域表示切面。旋转主视图不改变小窗方向。
5. 点击「应用裁切并封口」生成真实网格，默认自动封口。可切换「切割预览 / 处理结果」，不再提供原始模型视图。结果视图显示真实几何及黄色封口面。
6. 从顶部「导出」下载当前尺寸的 STL。面板底部仅保留应用按钮，处理时可取消。

添加底座：切换到「添加底座」后，底座默认置于模型下方。单击底座显示 Three.js `TransformControls` 位移 gizmo；X/Y/Z 箭头分别控制左右、上下、前后，Shift 吸附到 1 mm，Esc 或「完成」收起控件。添加底座模式不显示 Bottom view，面板提供形状、等比大小滑杆、Y 轴旋转和颜色；大小滑杆范围为 0.25–3 倍，不显示尺寸，旋转范围为 −180°–180°。缩放以底座顶部中心为基准，保持与模型的接触高度；旋转围绕底座自身竖直轴。颜色可选预设或输入 HEX。底座位置、缩放和旋转会保留在导出的 STL 中；颜色和贴图仅用于预览，STL 不保存外观。模型和底座作为多个壳体一起导出，不执行布尔融合。

基础形状及自定义纯色底座预览使用轻微 clearcoat 和 sheen 的 `MeshPhysicalMaterial`，保持零金属度与中等粗糙度，让高光更宽、更圆润；这只影响预览材质，不改变导出的几何。

贴图示例：从顶部「示例 / Sample」选择「Cartoon chicken」，再进入「底面处理 / Base」。主视图保留模型贴图、UV、逐面材质及顶点颜色；删除区域为半透明红色，实时截面与新增封口为实心黄色。左侧 Bottom view 始终显示灰色白模与黄色切面，不显示贴图或顶点颜色。

切面中心为模型中心在当前切面上的正交投影，只沿法线偏移，不积累侧向位移。切换方向时保持切入比例（初始 5%），深度毫米数和滑条范围按新方向重新计算。「翻转保留侧」和底面预览同步更新。更换方向清除旧裁切结果，重复点击当前方向不清除结果；加载新模型恢复 Y。Add Base 保留独立的位移 gizmo 和 Shift 1 mm 吸附。

初始尺寸采用工作台设定的模型高度（默认 80 mm）。修改切割方案会清除旧结果；重新应用始终使用独立原始副本。仅修改尺寸不需要重新裁切，导出会应用缩放，并将切面旋转到水平 Z=0。结果仅在本次会话保留，顶部项目保存/备份仍保存工作台原项目。STL 不含纹理或颜色。

## 实现边界

- `engine/base-processing`：三角形与平面求交、边界闭环、含孔轮廓三角化、共线边界点恢复、拓扑统计、二进制 STL 输出。`clippedBounds` 计算保留三角形及新交点的包围盒，无需执行封口即可更新尺寸。
- Web Worker 执行裁切和检查；传入独立数组副本，取消操作终止 Worker；任务编号防止旧结果覆盖当前模型。
- `feature/base-processing`：会话参数、尺寸与等比缩放、模型切换同步、结果失效与取消、独立 Three.js 画布；添加底座模式额外维护底座形状、尺寸、XYZ 位移、颜色和位移 gizmo。卸载清理 GPU、监听器和 Worker 资源。
- 外观数据取自工作台 `PrintMeshInput` 的独立副本。已烘焙的 sRGB 顶点颜色转换为线性 RGB，避免重复乘材质颜色。主视图异步解码贴图；切换模型、卸载或旧请求完成时释放纹理和 ImageBitmap，旧贴图不会覆盖新模型。Bottom view 使用单一灰色材质，不加载贴图。
- 预览和处理结果都使用原始贴图表面与相同切平面进行 GPU 裁切；处理结果叠加裁切引擎生成的真实封口面。裁切引擎及 STL 导出仍输出真实裁切几何，不新增贴图导出能力，也不为新切面生成贴图。
- 主视图与底面小窗在预览时使用有符号 stencil 计数实时填充黄色截面，正常闭合网格的孔洞得到保留；应用后改为显示真实封口三角形。主视图截面随深度、旋转、翻转和缩放同步，按深度关系被模型表面遮挡。原始网格存在破洞、朝向错误或重叠壳体时，预览高亮可能不准确，最终以实际裁切校验为准。
- `Workbench.vue` 负责入口、公共栏和导出路由。返回其他模块时恢复其原视图与数据。

自动封口处理新切口，保留轮廓中的孔洞。不做原有破洞修复、壳体布尔合并、自相交消除、最小壁厚判断或语义底座识别。「基础检查通过」仅说明开放边、非流形边、相邻面方向、退化面和重复面检查通过，不等于完整可打印认证。遇到不闭合、相交、重叠或分叉的切口会提示调整切面或修复模型。

裁切限制为 200 万三角面和 12,000 个切口顶点；直接 STL 序列化允许最多 400 万面，以容纳模型与高精度底座的组合。复杂轮廓检查可能较慢，可取消。非常接近的顶点按模型包围盒尺寸的 1e-7 容差焊接，极细小结构或互相接触的壳体需要检查。尺寸输入拒绝非正数、非有限数和使最大边超出 0.01–100,000 mm 的缩放；空裁切禁用应用与尺寸编辑。

## Add Base 立体文字（2026-11-19）

Color 下新增 Text 区：输入内容后点击 Add text，默认文字为 Text；支持最多 32 个字符、实时编辑、0.35–3 倍等比缩放、选择和移除。仅保留一个可编辑文字对象，文字使用独立的浅金色材质。英文字形使用随包字体，中文等字符在浏览器中提取系统字体轮廓后挤出，都是带真实厚度的网格；不同系统字体及复杂字形边缘可能存在差异。

可直接拖动文字，也可单击文字显示 XYZ 平移 gizmo；底座和文字的选择互斥，Esc 或空白单击结束编辑。直接拖到底座时以射线命中位置作为放置点，并查询底座真实网格在该 X/Z 的最高表面；箭头移动在接近表面时吸附，拉远后释放，底座轮廓外不吸附。当前仅支持底座上表面，文字保持直立，不自动贴合侧面或模型表面，不做曲面变形。吸附后文字跟随底座平移、Y 旋转及缩放后的锚点位置，文字大小仍由独立的 Text scale 控制。文字底部嵌入 0.08 mm 以避免共面；曲面接触按文字中心采样，不保证所有字母或长文字均与底座相交。

文字修改使 Add Base 确认状态失效；空白内容提示错误并禁用确认和导出。文字网格由 controller 保存，预览与 STL 共用变换，切换模块再回来可重建；更换模型清空文字。STL 沿用模型、底座、文字壳体组合导出，不执行布尔融合，也不包含颜色。

## 移动与缩放组合 gizmo（2026-11-19）

底座和文字共用一套组合控件：选择对象后同时显示 XYZ 平移箭头、朝向屏幕的包围框与四角方形缩放手柄，无需切换模式。包围框随模型位置、尺寸和相机视角更新，角点保持固定屏幕大小；悬停只高亮当前角点，缩放时淡化其他手柄与箭头并在拖动角点附近显示实时倍率。左侧移除 Scale / Text scale 滑杆，保留精确倍率输入；Y 轴旋转滑杆不变。

## 曲面吸附稳定性（2026-11-20）

文字直接拖动和 gizmo 平移期间启用连续表面追踪：从上一接触点小步验证到候选位置的路径，拒绝跨越断面或突然跳到另一片表面。局部多点法线采样仅在平缓区域内平均，再按移动距离平滑朝向；沿用上一帧的文字坐标方向，移除跨顶面 / 侧面阈值时的上方向突变。

形变从整段文字的固定方向投射改为局部曲面网格：先沿文字基线跟随表面弧长，再向上下扩展，每个网格单元验证相邻距离、朝向和外侧偏移，字间空隙也参与连续性检查。背面与正面沿局部法线保持厚度，查询只在预测位置附近寻找表面，避免射线捕获远处云瓣。深凹槽、锐利边缘、大幅折返和不能容纳整段文字的区域仍会拒绝；这不是任意曲面的全局无自交参数化，也未实现逐字符刚性排布。

靠近已有有效位置时的临时贴合失败不立即解除吸附，保留上一套网格、位置与朝向并提示；有效候选恢复后继续跟随。轮廓附近先尝试 12 px 邻域捕捉，在上次有效指针位置 24 px 内可容错保持，明显拖离后恢复自由移动。随有效贴合位置更新自由拖动基准，减少解除吸附时的位置突跳。松手、取消、模块切换、删除与控件销毁会清理拖动状态；字体、缩放和内容改变仍重新验证贴合。

拖动指针事件合并为每渲染帧一次计算，松手前处理最后一次移动，取消则丢弃待处理事件。当前始终显示已校验的实际网格，未引入松手后二次替换几何。面板布局保持原样，视图区提示区增加已贴合 / 保留最近有效贴合反馈。
