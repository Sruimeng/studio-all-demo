# Tripo Material Studio

独立、免登录的材质与多色打印展示工作台。GLB / FBX → 耗材验证 / 自动分色 → 区域绑定 SKU → CSV / JSON / 3MF。内置 Polymaker Panchroma PLA 数据与 OpenPBR 参数子集预览，支持中英文。

## 运行

Node.js 22+，pnpm 10：

```sh
pnpm install --frozen-lockfile
pnpm dev
```

打开 http://127.0.0.1:3100 。

```sh
pnpm typecheck
pnpm lint
pnpm test
pnpm build
python3 -m http.server 3101 --bind 127.0.0.1 --directory .output/public
```

静态产物在 `.output/public`，部署在站点根路径。无需后端。WebGL、Worker、IndexedDB 和 OffscreenCanvas 需要现代浏览器；生产环境使用 HTTPS。

## 演示

1. 多色打印与打印准备默认使用角色模型（去光），Segment 默认使用小鸡（Cartoon chicken）。切换默认示例时分别保存并恢复各自项目；顶部「示例」打开当前模块的默认模型。已有保存项目优先恢复，旧小鸡打印项目首次升级时先保留再打开角色模型。也可选择一个 GLB / FBX，FBX 配套贴图在同一次选择中加入。
2. 选择最多 1–12 个耗材，生成分色。模型采样色自动匹配到 Polymaker SKU；区域卡显示颜色名、材料类型、代表色 → 色卡 HEX 与近似 ΔE00。Surface 使用面标签，UV texture 使用纹理标签与三角细分。
3. 默认进入原模型与材质的对比视图。拖动中间分割线调整左右比例；点击区域，再应用右侧材质，更换材质不会重算区域。
4. 点击「导入 USDA 材质」可多选 `.usda`，提取 OpenPBR 材质并保存到本地库，点击后应用。也可新建本地材质，或从 Polymaker 库搜索 SKU、颜色名、材料类型。色卡只展示颜色；表面效果在中央 3D 视图评估。调整参数时实时预览，保存写入本地，取消恢复。
5. 打印高度 10–320 mm，默认 80 mm；可开启 0.2 mm 层纹，切换原模型、材质或同步相机对比。首次进入默认中文；顶部「导入模型」旁可切换中英文，语言选择会保存在当前浏览器。中文保留原有文案，英文覆盖拆分、耗材、打印准备及状态提示；切换仅影响界面显示，不修改模型与方案。
6. 保存项目后可刷新恢复。项目与备份面板可切换项目、导出 ZIP 备份和恢复备份。
7. 勾选部分材质或导出全部 CSV / JSON；顶部导出当前区域 3MF。四色自检文件用于检查区域叶编码。

`public/samples/role-model.glb` 是多色打印与打印准备的默认模型，来自用户提供的「角色模型（去光）.glb」，内置全部贴图。`public/samples/cartoon-chicken-textured.glb` 保留为 Segment 默认示例，内置贴图与 UV。资源随静态产物分发。生成参考图为 `public/samples/cartoon-chicken-reference.png`（用户提供的 1024×1024 高清原图）；旧 JPEG 仅保留用于历史方案导出。白模示例 `stylized-turkey-white.glb` 来自另一次生成，不与小鸡直接互套面索引。原松树和宇航员资源保留。

## Polymaker 验证

1. 点击「打开标准样件」，进入「材质验证」；也可导入实物样件对应的 GLB / FBX。
2. 选择 SKU，整模应用材质并保留源几何与法线。固定 Studio HDR、ACES、曝光 1、环境强度 1、旋转 0；层纹默认关闭。
3. 默认使用表格 HEX。供应商颜色空间未确认，编辑器提供线性 sRGB / sRGB 两种试验解释。源颜色原值保留；本地 HEX 调整优先。
4. 参数调整保存在独立供应商覆盖库，可恢复供应商参数。保存项目或 ZIP 备份保留预览模式、环境配置、选中 SKU 和区域快照。
5. 切换「区域应用」，生成分色自动匹配 SKU，也可手动替换后导出 3MF。更换 SKU 不重算标签；「材质验证」期间禁用 3MF 导出。

首批表格有 26 个 SKU，ZIP 有 16 份 USDA：14 个对应、12 个仅颜色、2 个未对应。自动分色在 26 个色卡候选中，用 HEX 推导的 sRGB/D65 Lab 和标准 CIEDE2000 选近似 SKU。本地预览调整不改变匹配依据；ΔE00 是生成时采样色至色卡的面积加权平均，不是实物误差。未对应 SKU 可查看来源，暂不能应用。异常 Lab、颜色名冲突、越界颜色及文件名后缀均显示待复核提示。

本批无外部贴图，透射、清漆等权重为零。网页使用 Three.js 的 OpenPBR 参数子集，尚未验证 Blender 对照与实物一致性。对比视图左侧仍是原模型。标准样件含平面、曲面、连接在平面顶部的薄壁；打印高度会统一缩放壁厚。本批不透明材质不能验证透射。

```sh
python3 scripts/import-polymaker.py '颜色数据.xlsx' 'PLA_Basic.zip'
node scripts/create-material-check.mjs
```

转换脚本只支持本批单个 OpenPBR 节点的常量输入；外部资源、组合和有效连接输入会报错。完整契约见 [供应商材质](llmdoc/reference/supplier-materials.md)。

本地材质可在「本地」页签点击垃圾桶并确认删除。删除保存在当前浏览器；已应用的区域与项目材质快照保持原样，内置供应商档案不可删除。

## USDA 上传

单文件最多 20 MB、1–100 个材质。只提取绑定 OpenPBR 节点的常量参数，忽略模型几何。保存文件名、SHA256、源参数与材质文本；同名记录自动添加 `-IMPORT-N`，保留内置 SKU。导入材质默认按线性 sRGB 预览，源颜色空间仍待确认，可编辑颜色解释与外观参数、恢复源参数。

支持本批颜色、金属度、粗糙度、IOR 与不透明度。外部贴图、组合、有效连接输入及透射、清漆等未支持效果会报错。多文件逐个反馈，成功项保存在当前浏览器。导入材质可手动应用，未建立 SKU 色卡对应前不加入自动分色候选。

## 数据与边界

- `MaterialRecord`：稳定内部 ID、唯一用户 ID、名称、sRGB HEX、透明度、金属度、粗糙度、参考图。RGB 从 HEX 无损推导，CSV 显式包含 RGB。
- `PrintProject` v2：原模型及配套文件、区域快照、材质绑定、打印尺寸、分色参数、完整预览配置与验证材质。兼容 v1 项目；旧材质保留 Studio 规则。模型文件仅写浏览器 IndexedDB。
- `RegionAssignment`：区域序号、模型代表色、材质快照；可选 `RegionColorMatch` 保留匹配依据、稳定材质 ID、色卡 HEX、平均 ΔE00 与采样面积比例。手动换材质清除匹配记录，旧项目恢复原绑定，重新分色替换当前绑定。相同颜色不同 ID 保持独立。
- JSON 含格式版本、来源、原始 USDA 材质文本、本地调整、区域映射及完整选区快照；ZIP 额外携带模型与供应商覆盖库。恢复 ZIP 会替换本地材质库，v2 同时替换供应商覆盖库。
- CSV 包含展示 HEX/RGB、SKU、材料类型、Pantone、D65 Lab、文件版本与问题标记；未对应 SKU 的颜色为空。Studio 粗糙度为 `0.5 + 0.5 * (roughness * roughnessMap.g)`；OpenPBR 子集直接使用输入粗糙度。透明度映射为 `opacity = 1 - transparency`，不等同于透射。
- 3MF 使用毫米、统一色槽与 SKU，附 `Metadata/materials.json` v2；材料类型和品牌来自供应商，本地未知材料类型为 `Unknown`。PBR 外观参数仅作附加元数据，不转换成切片器贴图或打印工艺。没有验证指定切片器或实际打印结果。
- 已装配 Meshopt。未装配 Draco / KTX2 解码器，相关资源会明确报错。
- FBX 缺少的金属度/粗糙度使用 0/1；已有 Phong 信息按移植规则换算。缺失、歧义或无法解码的贴图会显示提示。
- 顶点色与贴图同时调色时保留原显示，并按线性空间乘积做表面分色；该材质的低模路径使用表面投影，修色需使用 Surface 模式。UV 重叠岛共用纹理标签。
- 独立 Multi-color 可显式保存；进入打印准备后，分色、尺寸及准备进度自动保存到当前项目。浏览器清除站点数据会清除本地项目，跨设备或外发使用 ZIP 备份。

架构与来源见 [llmdoc/index.md](llmdoc/index.md)，验证记录见 [llmdoc/guides/verification.md](llmdoc/guides/verification.md)。


## Print Preparation

Multi-color 顶部「我的耗材」显示数量和颜色预览。展开后以色块、品牌、系列/材质展示列表，点击查看详情及独立 3D 样件；删除需确认。底部支持按品牌、系列、材质、颜色名、SKU 和 HEX/RGB 组合检索，选择结果后点击添加，无匹配时可命名、选择材质与相近颜色创建本地耗材。拥有列表保存到当前浏览器；添加、移除及样件查看不修改模型分区、耗材绑定或打印确认。重新分色时使用最新拥有列表；开启优先使用后，自定义耗材也参与候选匹配。自定义耗材保存所选材料类型，并用于打印导出。

左侧 Print 面板顶部集中展示切片器、单色/多色模式及等比例尺寸确认；下方打印清单仅包含基础网格检查和多色模式的颜色设置摘要。尺寸必须先确认，才可复核检测结果。主动切换多色且没有已确认结果时，进入现有 Multi-color；所有颜色入口都复用同一编辑器。

从打印准备进入时，「完成并返回」校验当前模型版本、全区域标签和耗材，保存成功后确认；普通返回只保存草稿。精修入口置于模型底部 bar：画笔与色块填充分别展开简约工具条，笔刷大小支持滑杆和数值输入。统一使用左侧「方案耗材」选色；色块模式先选方案耗材，再点击模型直接填充连通色块；悬停描边预览填充范围，每次有效填充记为一步撤销。同色点击不新增编辑。取色器只切换当前耗材，取色后返回原工具；空白处拖动保持旋转。关闭工具只结束精修，UV 岛入口暂时隐藏。编辑已确认的分区或耗材后标记待复核；单纯选择、查看和等比例缩放不清除颜色确认。每个项目保存独立的模式、尺寸确认、清单、切片器、分色签名和返回来源，刷新不会再次自动跳转。未拥有耗材不阻止导出。

基础检查实际统计开放边、非流形边、退化面、重复面和边朝向。薄壁、自相交及设备适配未接入，自动修复不可用；用户明确复核检测结果后可继续导出到切片器处理，复核不代表网格已修复或已保证可打印。改变尺寸取消尺寸确认和检测复核，展开检查项并阻止导出；重新确认尺寸后仍需重新复核。重复确认相同尺寸不会使已复核状态失效。

单色生成按毫米缩放的 STL。多色沿用含 Bambu/Orca 分区字段的 3MF，并固定已确认分区，不因导出时缩放重新分色。Bambu Studio / OrcaSlicer 可下载此格式，具体切片器版本和实际打印仍需验证；Creality Print / Anycubic 的多色映射未验证，当前禁止该目标的多色导出。「导出模型文件」按当前模式下载文件；下方「一键导入 [切片器]」随目标切片器更新名称，尚未接入服务，保持禁用。底部不显示额外说明，不显示「已导入」、不扣积分。清单未完成、保存失败或处理中均禁用导出，悬停可查看原因；保存失败仍提供重试。Multi-color 面板已移除单独的材质预览模块。

## Segment 参考图拆分示例

面板顶部提供“自动拆分 / 自定义拆分”，默认进入自定义拆分，新模型默认选择部件拆分。自定义拆分内保留部件/颜色两种模式及原有编辑流程。自动拆分仅展示粗略（3–6 个部件）、标准（6–15 个部件）、精细（15+ 个部件）三档示意卡，默认标准，支持点击和方向键切换；切换一级面板后保留当前精度。卡片下方的“开始拆分”暂不可操作，不执行任务或扣费。切换一级面板不会修改自定义拆分的要求和结果。模型选择和“示例说明与版本”统一固定在面板底部，上方设置区域独立滚动。

进入 Segment → 选择模型 → 选择部件/颜色拆分 → 编辑输入框中的默认要求 → 点击“开始拆分” → 预览并通过 2D 分区调整 → 确认拆分结果。提示词下方新增“2D视图预览分件方案”，默认不勾选，按模型及部件/颜色模式记住选择。不勾选时点击“开始拆分”直接生成示例 3D 候选；勾选时先生成参考图分区并打开 2D 精修弹窗，此时不计算 3D 面归属，也不替换已有结果。弹窗可修改提示词，点击“更新分区方案”刷新预览；提示词与预览不一致时禁用确认，覆盖手工编辑前需确认。点击“确认方案并拆分”后关闭弹窗，显示拆分状态，再生成 3D 候选。取消弹窗保留原提示词、原结果及确认状态。输入框下的“开始拆分”直接执行当前路径，不再展示“替换手动调整的方案”二次确认卡片。生成失败恢复编辑方案供重试，保存失败保留 3D 草稿并提示重试。首次与再次拆分均使用“开始拆分”文案。修改提示词、预览选项及切换拆分模式保留原始模型/分件方案的当前选择；待更新或新模式暂无结果时仍可查看上次分件网格，但不能将其作为当前设置的有效结果确认。只有明确开始拆分并生成结果后才自动切到分件方案；取消 2D 预览、编辑已有方案或保存结果不切换视图。已有结果仍可点击“调整 2D 分区”编辑，也可修改提示词并更新方案。确认并保存成功后才允许导出部件、将结果传入 Multi-color/Print。改名、合并或应用分区变更后需再次确认；单纯查看或取消编辑保留原确认状态。小鸡示例提供“身体、鸡冠、喙、双脚、背包、右侧配件”等候选；颜色模式按固有色归组。拆分要求输入框始终展开，保留默认描述，移除快捷预设和辅助说明；面板已移除拆分细节三档设置，两种模式分别保存草稿，模型版本用几何指纹隔离。

2D 画布直接使用用户提供的 1024×1024 高清原参考图，编辑蒙版保留 1024×1024 分辨率，不使用 3D 渲染替代。分区清理细小误分类和反光碎点，平滑前景内的边界，保留轮廓、背景间隙与同部件不相连的区域。旧参考图方案会提示点击“开始拆分”，不会自动覆盖手工编辑；重新拆分后可恢复或下载旧方案，旧蒙版不会被套在新图上继续编辑或确认。有分区方案时固定并排展示左侧参考图与右侧分区；点击“调整 2D 分区”打开大弹窗，直接展示编辑工具栏，部件归属、应用修改与取消编辑均在弹窗内，右上角仅保留叠加/仅分区切换，叠加固定 60%，移除对比、适配、操作指引和透明度控件。支持缩放平移、部件选择、套索、笔刷涂改、区域归属、新建/合并/改名、撤销/重做、取消/应用。默认点选会选中所属部件的所有区域，包括不相连的部分；同步选中左侧部件，并在参考图与分区图上显示同一选区的边缘线。套索保留局部选择能力，背景不可成为部件。应用后关闭弹窗，回到 3D 展示“拆分中”状态并检查、保存修改，取消则恢复编辑前方案。移除主画布的 3D/2D 视图切换；模型选择区仅展示无标题的下拉框与“示例说明与版本”折叠入口，参考图在 2D 编辑弹窗中查看。整组分配、合并和改名可以从生成前的 2D 预览传递到示例 3D 分件，背面或不可见组不会丢弃。局部 2D 边界修改仍需算法映射；生成前预览中保留编辑并提示，可撤销后继续，不生成与方案不符的 3D；已有结果的局部 2D 修改沿用保存草稿及下载 JSON 方案的流程。

2D 编辑工具更新：左右两侧默认点选整个部件，套索选择局部，选区同步描边。移除对象选择按钮及框选吸附；套索、笔刷再次点击退出后恢复默认点选。Command/Ctrl 加选、Option/Alt 减选，空白点击或 Esc 清空。空格拖动同步平移，滚轮同步缩放。底部沿用模型笔刷工具栏的图标、圆角色块和 Size 滑条/数值输入样式；顺序为撤销、重做、套索、笔刷、新建、吸色、色块和当前工具设置，色块旁不显示部件名。部件色板独立设置分配/笔刷目标，选择颜色不自动修改；点击“分配”后清空选区并保留目标。笔刷改为仅在右侧直接涂改，硬边、无颜色混合，有选区时限制在其中；背景与隐藏部件不可涂改，松开一次记为一次撤销，Esc 中止未提交笔画。吸色从任一侧读取对应部件归属，成功后返回原工具。新部件在首次有效分配或涂抹时创建，避免空部件。撤销/重做支持 Command/Ctrl+Z、Command/Ctrl+Shift+Z，输入框内优先处理文字；切工具、目标和撤销保留可用选区。关闭弹窗有未应用修改时提示放弃或继续编辑；Esc 优先结束手势、关闭色板或清选区。
